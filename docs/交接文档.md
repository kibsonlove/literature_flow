## 1. 项目一句话

通用文献管线工具（FastAPI 网页应用）：检索（OpenAlex/arXiv）→ 入库 Zotero → 批量精读生成笔记 → 知识库语义检索 → 维护工具箱。当前正准备**改造为智能体**（LLM 规划 + 工具调用），方案已定稿、代码未动。

## 3. 已拍板决策（不要重新讨论）

1. LLM 默认走**网页端 webchat**（零 API 费）；API 只作设置里的备选。
2. 编排用**粗粒度规划**：一次出计划 → 确定性执行 → 失败才回问 LLM。不做逐步决策紧循环（webchat 每次开浏览器约 30 秒+）。
3. 首发**交互式面板**，自动化/定时放 P3。
4. 任务**只串行**（webchat 同一浏览器 profile）。
5. 写库步骤必须人工确认，agent 无静默写权限。
6. 不用 LangGraph 等框架重构。

## 4. 接手第一步

按方案第 2 节做 **P0**：新建 `webapp/core/agent_tools.py` 工具注册表（纯新增、零风险），
验收标准是能导出一份"给 LLM 看的工具说明书"。动手前先读方案的硬约束（第 3 节）与风险表（第 4 节）。

## 5. 关键文件指引

| 文件 | 作用 |
|---|---|
| `webapp/app.py` | 全部路由（`grep "@app."` 可速览） |

| `webapp/core/kb.py` | 知识库语义检索（`other_language_query` 刻意走 API，别"优化"掉） |
| `webapp/core/tools.py` | 白名单脚本运行器——工具注册表的现成范本（TOOLS 字典 + danger/dry-run 分级） |
| `webapp/core/zotero_io.py` | Zotero 读写（写需授权：`write_authorized()`） |
| `webapp/core/config.py` | 所有路径/配置读取函数（路径禁硬编码，一律走这里） |
| `webapp/core/prompt.py` | 模块级 `__getattr__` 动态转发 `domain.system_prompt()` |
| `webapp/start.local.bat` | 本机启动入口（服务 127.0.0.1:8000） |

## 6. 红线速查（违者返工）

- **改已有文件先说明方案征得同意**；删/合并先出清单。
- 指定文献必须走「从 Zotero 选择」`openZoteroPicker()`，禁止让用户粘贴 Zotero key。
- 方案选择必须用弹窗（AskUserQuestion）。
- 测试不拿用户真实文献端到端；写库测试用可整删的小样。
- 自动分类只在现有分类树内匹配，绝不新建分类；归属是移动制。
- 指纹字符串 `"六维速览"`/`"六维精读"` 不能改（历史笔记识别用）。
- .bat 文件纯 ASCII + CRLF。
- 前端样式约定：按钮悬停 `filter: brightness(.93)` 不改背景色；`.muted` = `#6b6b6b`。

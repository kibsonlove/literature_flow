# literature_flow

把 Zotero 变成你的 AI 文献助手：自动精读论文、把笔记写回 Zotero、再把全文建成能用大白话检索的知识库。

整套流水线跑在你自己电脑上（一个本地 Python 服务 + 你自己的 API key），不需要任何云端账号，文献数据始终留在本机。

---

## 一、环境配置
1. 初次下载，打开webapp文件夹，点击setup.bat自动装配环境
2. 点击start.bat，进入网页界面使用

---

## 二、它能做什么

| 功能 | 说明 |
|---|---|
| **单篇精读** | 挑一篇带 PDF 的文献，AI 按学科维度出一份结构化笔记，直接写进 Zotero |
| **批量精读** | 勾选一批文献，后台逐篇生成笔记，可随时停止 |
| **长文精读** | 学位论文 / 专著：先分章精读，最后自动汇总一份「全书总纲」 |
| **PDF 入库** | 把散落各处的 PDF 批量建成 Zotero 条目（自动补全 DOI 元数据） |
| **文献检索** | 按自定检索式从 OpenAlex / arXiv 找文献，勾选后一键入库 |
| **文献订阅** | 按你给的期刊名单和关键词，定期捞出新发表的候选文献 |
| **语义检索** | 全文切块做向量化，用自然语言提问，给出原文段落出处 |
| **论文对比** | 把所有笔记的速览维度汇总成一张表，横向对照、导出 CSV |

**笔记的维度不是写死的。** 程序会按文献内容自动匹配学科模板（「领域包」）——匹配不上就让 AI 当场造一个。你也可以自己增改领域包来定义某个学科该看哪些维度。

**笔记不会落在本地文件里。** 它的归宿始终是 Zotero：生成后经你确认，程序把它作为**子笔记**挂到对应文献条目下（条目原本不在库里就自动新建）。所以知识沉淀只有一个地方——Zotero 库，换电脑时备份 Zotero 就够了。

## 三、怎么用

### 精读一篇文献

1. 在主页点 **「从 Zotero 选择」**，在弹出的选择器里搜索或翻分类树，挑一篇**带 PDF** 的文献
   （选中后输入框显示标题，不需要你知道任何编号）
2. 选好后端（见下），点 **「生成笔记」**
3. 等进度条走完，网页上出现笔记预览，可以直接编辑
4. 确认无误后点 **「确认回写 Zotero」**——笔记就挂到那篇文献下面了

只有 PDF、还没入库的，直接点 **「上传 PDF」**：建条目 → 挂附件 → 抽全文 → 出笔记，一条龙。

### 两种后端

| 后端 | 费用 | 速度 | 说明 |
|---|---|---|---|
| **网页端 WebChat**（默认） | 免费 | 较慢 | 用你已登录的网页版大模型；首次需先登录一次 |
| **DeepSeek API** | 按量计费 | 快 | 需要配置里有可用的 key |

### 顶栏功能怎么用

| 按钮 | 用来做什么 | 怎么操作 |
|---|---|---|
| **PDF 入库** | 批量把 PDF 建成 Zotero 条目 | 选文件（可多选）或整个下载文件夹 → 上传入库 |
| **批量笔记** | 一次跑几十篇精读 | 「读取候选」自动列出"有 PDF 但还没笔记"的文献 → 「开始批量」，可随时停 |
| **论文对比** | 横向对照读过的文献 | 打开即汇总所有笔记的速览维度，可筛选、导出 CSV |
| **语义检索** | 按内容找证据、跨文献问答 | 先点一次「更新索引」建库，之后用自然语言提问 |
| **文献检索** | 找新文献并入库 | 填检索式（每行一条，支持 AND / OR / NOT 与双引号短语）→ 检索 → 勾选 → 入库选中；检索式可存成「主题」复用 |
| **工具箱** | 跑各类维护脚本 | 订阅候选清单、覆盖矩阵、素材包、标签扫描、重复扫描等，点按钮即跑 |
| **设置** | 填配置、看体检 | 大模型、本机路径、向量模型、OpenAlex、Zotero 写入授权；缺必填项时页面顶部会弹引导横幅 |

长文精读在主页 **「长文精读（论文/专著）」**：上传 PDF 或从 Zotero 选。建议先填「限 N 章」小跑几章试效果，再放开跑全书。

## 四、目录结构

| 目录 / 文件 | 内容 | 要不要动 |
|---|---|---|
| `webapp/` | 主应用（FastAPI + 原生前端） | 代码别改 |
| `webapp/start.bat`、`serve.bat`、`setup.bat` | 一键装环境 / 日常启动 / 后台重启 | 平时只用这几个 |
| `webapp/config/` | 你的密钥、Zotero 路径、领域包模板 | ✅ 就动这里——或者直接在界面「设置」里改 |
| `webapp/cache/` | 运行数据：向量库 `kb.sqlite`、MinerU 解析缓存 | 别手动改；删了会重建 |
| `webapp/logs/` | 服务日志 | 可随时删 |
| `scripts/` | 独立脚本：`subscribe/` 订阅、`pipeline/` 汇总、`dedup/` 去重、`tags/` 标签分析 | 用到时再说 |
| `scripts/subscribe/` 下的 `.txt` | 订阅的期刊名单与关键词 | ✅ 想订阅什么就编辑这两个 |
| `notes/` | 写作素材包，工具箱按固定路径读写 | **别改文件名** |
| `reports/` | 工具箱生成的 HTML 报告、订阅候选清单 | 看看就好 |
| `docs/` | 《项目架构与开发指南》：架构图、模块职责、数据流 | 想读懂代码时看 |
| `README.md` | 本文件——功能、用法、目录结构的唯一出处 | — |

想读懂代码结构、改功能或深入排错，见 **`docs/项目架构与开发指南.md`**（技术栈、模块职责、数据流、架构图）。

# literature_flow

把 Zotero 变成你的 AI 文献助手：自动精读论文、把笔记写回 Zotero、再把全文建成能用大白话检索的知识库。

整套流水线跑在你自己电脑上（一个本地 Python 服务 + 你自己的 API key），不需要任何云端账号，文献数据始终留在本机。

---

## 一、它能做什么

| 功能 | 说明 |
|---|---|
| **单篇精读** | 挑一篇带 PDF 的文献，AI 按学科维度出一份结构化笔记，直接写进 Zotero |
| **批量精读** | 勾选一批文献，后台逐篇生成笔记，可随时停止 |
| **长文精读** | 学位论文 / 专著：先分章精读，最后自动汇总一份「全书总纲」 |
| **PDF 入库** | 把散落各处的 PDF 批量建成 Zotero 条目（自动补全 DOI 元数据） |
| **语义检索** | 全文切块做向量化，用自然语言提问，给出原文段落出处 |
| **文献订阅** | 按你给的期刊名单和关键词，从 OpenAlex 检索新发表文献 |
| **论文对比** | 把所有笔记的速览维度汇总成一张表，横向对照 |

笔记的维度不是写死的：程序会按文献内容自动匹配学科模板（「领域包」），匹配不上会让 AI 现造一个。你也可以在 `webapp/config/domains/` 里手动调整维度。

---

## 二、准备工作

- **Zotero** 已安装且能正常打开（本地实测 **10.0.3**，Zotero 7 及以上均可）。本程序通过它的**本地 API** 读写，不碰你的云端账号
- **Python 3.10 或更高版本**
- 一个 **LLM 的 API key**（DeepSeek 或任意 openai 兼容服务都行）
- 可选：一个 **Embedding API key**，只做「语义检索」时需要。硅基流动的 `BAAI/bge-m3` 免费注册即可用

## 三、安装与启动

**推荐：双击 `webapp\setup.bat`**。它会自动做完三件事，你不需要敲任何命令：

1. 找到电脑上的 Python（没装的话会提示安装，能用 winget 的话可以一键装）
2. 在 `webapp\venv` 建好独立运行环境、装齐依赖包
3. 探测你的 Zotero 数据目录与程序位置，写进配置

跑完之后**双击 `webapp\start.bat`** 启动，浏览器自动打开 `http://127.0.0.1:8000`。
关闭程序：关掉那个黑色命令行窗口即可（不影响 Zotero）。

<details>
<summary>想手动装，或者 setup.bat 出问题时（点开看）</summary>

```bash
cd webapp
python -m venv venv
venv\Scripts\pip install -r requirements.txt

# 可选：想用「网页端」模式（走网页版大模型，零 API 费用）再执行这两条
venv\Scripts\playwright install chromium     # 下载浏览器内核，约 150MB
venv\Scripts\python login_deepseek.py        # 弹出浏览器登录一次，登录态会保存

# 启动
venv\Scripts\python -m uvicorn app:app --host 127.0.0.1 --port 8000
```

</details>

> 另有一个 `serve.bat`，只重启服务、不弹浏览器，日志写到 `webapp/logs/server.log`，适合后台跑。

> **双击 start.bat 后一闪而过 / 报 `No module named 'uvicorn'`**：说明依赖还没装，先跑 `setup.bat`。
> `start.bat` 会优先用 `webapp\venv`，没有就退回到系统 `python`。

## 四、配置：填什么、在哪里填

**绝大多数配置都在界面里填**：启动后点右上角「设置」。缺必填项时页面顶部还会直接弹出引导横幅，点一下就跳过去。

| 填什么 | 在哪里填 | 说明 |
|---|---|---|
| LLM 的 `api_key` / `model` / `base_url` | 「设置 → 大模型」 | **必填**，不填无法生成笔记 |
| Zotero 数据目录、程序路径 | 「设置 → 本机路径」 | **点「自动探测」基本就能填好** |
| 数据目录（缓存 / 向量库 / 浏览器内核） | 「设置 → 本机路径 → 数据目录」 | 留空 = 放项目内；改到大磁盘也行 |
| 向量化服务的 `api_key` | 「设置 → 知识库向量模型」 | 只做「语义检索」时需要 |
| MinerU 平台 key | 「设置 → 知识库向量模型 → MinerU API Key」 | 可留空，见下方说明 |
| OpenAlex Key | 「设置 → OpenAlex」 | 可留空，只是检索额度低一些 |
| Zotero 写入授权 | 「设置 → Zotero 写入授权」 | 点按钮授权一次（选 Always Allow） |

**Zotero 路径不用自己找**：点「自动探测」会依次查 Zotero 的 profile 配置、注册表、桌面与开始菜单的快捷方式、Windows 运行记录——数据目录自定义过、Zotero 装在非默认盘甚至盘根，都能找出来。探测不到时可以点「浏览数据目录…」「选择 zotero.exe…」弹系统选择框（浏览器出于安全拿不到完整本地路径，所以由本机弹窗代选），也可以手填：数据目录就是 Zotero「编辑 → 设置 → 高级 → 文件和文件夹」里显示的「数据目录位置」（如 `D:/Zotero`）。

界面里点「保存」后立刻生效，不用重启服务。

补充说明：

- **不需要手工复制 `*.example.json`**。首次点「保存」时程序会自动在 `webapp/config/` 下生成对应的 `.json`；那两个 `example` 文件只是给你看格式的模板。
- **Zotero 不需要填任何 key**。它只监听本机，程序零配置即可连上——只要 Zotero 开着就行。
- **MinerU 平台 key**：在「设置 → 知识库向量模型」里填即可（mineru.net 注册即得）。
  - 不配也能正常**精读单篇文献**——只是会降级成纯文本处理，拿不到原文表格里的量化数据；
  - 但**「语义检索」和「长文精读」必须有它**：知识库是把 MinerU 的解析结果切块建索引的，没有解析缓存就没有东西可索引。
- **数据目录**（缓存、向量库、MinerU 解析结果、浏览器内核）默认放在项目里（`webapp/cache`）——删掉项目文件夹就能全部清理干净。想省系统盘空间，可以改到大容量磁盘；填的必须是绝对路径，留空就继续用默认。想单独指定浏览器内核或网页端登录资料目录，点开「高级」那一栏。
- **浏览器内核**：用「网页端」模式时才需要（它要驱动一个真实浏览器）。在「设置 → 本机路径 → 高级」里点 **「一键下载内核」**，会自动下到该处配置的目录（约 150MB），**装完不用再手填路径**；`setup.bat` 里也会问你一次。
- 这些配置都存在 `webapp/config/*.json`，都已写进 `.gitignore`，**永远不会被提交到仓库**。界面是主入口，直接改文件同样有效。

## 五、怎么用

### 精读一篇文献

1. 点主页的 **「从 Zotero 选择」**，在弹出的选择器里搜索或翻分类树，挑一篇**带 PDF** 的文献（选中后输入框会显示标题，不需要你知道任何编号）
2. 选好后端（见下方说明），点 **「生成六维笔记」**
3. 等进度条走完，网页上会出现笔记预览，你可以直接编辑
4. 确认无误后点 **「确认回写 Zotero」**——笔记就挂到那篇文献下面了

### 两种后端可选

| 后端 | 费用 | 速度 | 说明 |
|---|---|---|---|
| **网页端 WebChat**（默认） | 免费 | 较慢 | 用你已登录的网页版大模型；**首次需先跑一次 `login_deepseek.py`** |
| **DeepSeek API** | 按量计费 | 快 | 需要 `settings.json` 里有可用的 key |

### 其他常用操作

- **手边只有 PDF、还没入库**：主页点「上传 PDF」→ 会自动建 Zotero 条目、挂附件、抽全文、出笔记，一条龙。也可以用顶栏 **「PDF 入库」** 批量囤文献，之后再走批量精读。
- **已有几十篇想一起读**：顶栏 **「批量笔记」** → 「读取候选」会自动列出"有 PDF 但还没有笔记"的文献 → 开始批量。列表会自动跳过已有笔记的条目，不会重复生成。
- **学位论文 / 专著**：点「长文精读」，上传 PDF 或从 Zotero 选。可以先填「限 N 章」小跑几章试试效果，再放开跑全书。
- **想按内容找文献**：顶栏 **「语义检索」** → 先点一次「更新索引」建库（需要用 MinerU 解析过）→ 之后就能用自然语言提问。
- **想知道该读哪些新文献**：顶栏 **「工具箱」** → 先编辑 `scripts/subscribe/lit_keywords.txt`（关键词）和 `lit_journals.txt`（重点期刊），再点「运行订阅」。参考 `scripts/subscribe/` 下的两个 `.example.txt` 模板。
- **横向对比读过的文献**：顶栏 **「论文对比」**，可筛选、可导出 CSV。

## 六、笔记和数据存在哪里

**重要：精读笔记不会落在本地文件里。**

它的归宿始终是 **Zotero**——网页上生成、你确认后，程序把它作为**子笔记**挂到对应文献条目下（如果那条文献原本不在库里，会自动新建条目）。所以你的知识沉淀只有一个地方：Zotero 库。换电脑时备份 Zotero 就够了。

本地会产生的其他东西：

| 位置 | 内容 | 能删吗 |
|---|---|---|
| `webapp/cache/` | 知识库向量库 `kb.sqlite`、MinerU 解析缓存 | 能删，删了重新建索引即可，不影响 Zotero |
| `reports/` | 工具箱生成的 HTML 报告、订阅候选清单 | 能删，重新跑工具会再生成 |
| `notes/material_pack.md` | 写作素材包，工具箱「重建写作素材包」的产物 | 能重建，但**别改文件名**——工具箱按固定路径读写它 |
| `webapp/logs/` | 服务运行日志 | 能删 |

## 七、目录结构：哪些要动、哪些别碰

| 目录 / 文件 | 内容 | 要不要动 |
|---|---|---|
| `webapp/` | 主应用（FastAPI + 原生前端） | 代码别改 |
| `webapp/setup.bat`、`start.bat` | 一键装环境 / 日常启动 | ✅ **平时只用双击这两个** |
| `webapp/config/` | 你的密钥、Zotero 路径、学科维度模板（**不入库**） | ✅ 就动这里——或者直接在界面「设置」里改 |
| `webapp/cache/` | 运行数据：向量库 `kb.sqlite`、MinerU 解析缓存 | 别手动改；删了会重建 |
| `webapp/logs/` | 服务日志 | 可随时删 |
| `notes/` `reports/` `archive/` | 素材包、报告、历史产物（**不入库**） | 看看就好。`notes/` 被程序按固定路径读写，**别改文件名** |
| `scripts/` | 独立脚本：`subscribe/` 订阅、`pipeline/` 汇总、`dedup/` 去重、`tags/` 标签分析 | 用到时再说 |
| `scripts/subscribe/lit_journals.txt`、`lit_keywords.txt` | 订阅的期刊名单与关键词 | ✅ 想订阅什么就编辑这两个 |
| `docs/` | 《项目架构与开发指南》：架构图、模块职责、数据流 | 想读懂代码时看 |
| `README.md` | 本文件——安装、配置、使用、排错的**唯一出处** | — |

## 八、仓库包含什么、不含什么（推送范围）

仓库只包含**通用代码与文档**：给谁用都一样的部分会推上去；属于你个人研究数据的部分留在本地。

### 会推送到仓库的

- 全部程序代码：`webapp/`（除去 `config/` 真实配置、`cache/`、`logs/`）
- 脚本中**通用**的那几个：`scripts/subscribe/lit_watch.py`、`scripts/dedup/zot_dedup.py`、`scripts/tags/tag_analysis.py`、`scripts/pipeline/build_pack.py`、`scripts/debug/zot_read.py`
- 文档：`README.md`、`docs/项目架构与开发指南.md`
- 格式模板：`webapp/config/*.example.json`、`scripts/subscribe/*.example.txt`、`.gitignore`

### 不会推送的（已写进 `.gitignore`，实测逐条生效）

| 被忽略的 | 为什么 |
|---|---|
| `webapp/config/` 下的**真实**配置：`settings.json`、`paths.json`、`embedding.json`、`domain.json`、`topics/` | 含你的 API key、Zotero 本机路径、检索主题 |
| `webapp/cache/`、`webapp/logs/` | 运行数据与日志，可再生产 |
| `webapp/start.local.bat`、`serve.local.bat`（规则 `*.local.bat`） | 硬编码本机 Python 绝对路径的专用启动器 |
| `notes/`、`reports/`、`archive/` | 你的研究产物 |
| `scripts/subscribe/lit_journals.txt`、`lit_keywords.txt` | 你的期刊名单与关键词 |
| `scripts/pipeline/*`、`scripts/dedup/*`、`scripts/tags/*` 里的个人预设脚本与历史方案 | 含你的研究预设与本机路径 |
| `docs/research/` | 个人研究笔记 |
| `_trash_*/`、`dist/`、`build/` | 临时目录与构建产物 |

> ⚠️ `scripts/pipeline/extract_journals.py` 里写到过 `C:\Users\<用户名>\Desktop\毕业论文\…` 这类本机路径，
> 全靠 `scripts/pipeline/*` 这条规则挡着——**不要放开它**。
>
> ℹ️ 工具箱里点到这些未分发的个人脚本时，会提示「脚本未找到……部分个人分析脚本默认不随仓库分发」——
> 这是预期行为，不是故障。

想核对某个文件到底会不会被提交，在项目根目录执行：

```bash
git check-ignore -v <文件路径>     # 有输出 = 已忽略；无输出 = 会被提交
```

## 九、常见问题

| 现象 | 怎么办 |
|---|---|
| 浏览器提示"无法访问此网站" | 等 3～5 秒刷新；仍不行看命令行窗口的报错；重启 `start.bat`（它会自动清掉占用 8000 端口的旧进程） |
| 页面顶部有黄色引导横幅 | 说明还缺必填配置（大模型 Key 或 Zotero 数据目录）。点「打开设置」补齐，或「稍后再说」先关掉 |
| 页面能开，但选文献时列表是空的 | Zotero 没打开。先启动 Zotero 再重试 |
| Zotero 升级后提示「未找到 Zotero 程序」 | Zotero 升级会把 exe 挪位置，还可能清掉注册表项。「设置 → 本机路径」点「自动探测」（会查快捷方式与运行记录）；仍不行用「选择 zotero.exe…」手动指一下 |
| 点了「生成」但提示找不到 PDF | 「设置 → 本机路径」里的 Zotero 数据目录填错了。点「自动探测」重试，或按 Zotero「设置 → 高级 → 文件和文件夹」里显示的位置手填 |
| 点生成后报 key 无效 / 余额不足 | 去网页「设置」里更新 API key |
| 「语义检索」提示未配置向量模型 | 去「设置 → 知识库向量模型」填 API Key（默认用免费的硅基流动 BGE-M3） |
| 「语义检索」结果很少或为空 | 还没建索引，先点一次「更新索引」（另需 MinerU 解析缓存，见第四节） |
| 网页端后端报错说找不到浏览器 | 执行过 `venv\Scripts\playwright install chromium` 了吗？另外要先跑一次 `login_deepseek.py` 登录 |
| 笔记的维度不像我这个学科 | 领域包没匹配上，回退到了通用维度。可在 `webapp/config/domains/` 里给对应学科补关键词 |
| 精读出来的数字对不上原文 | 该文献还没被 MinerU 解析过，表格数据没喂给模型。去「设置 → 知识库向量模型」填 MinerU API Key 可改善 |

以上是使用说明的全部内容。想读懂代码结构、改功能或深入排错，见 **`docs/项目架构与开发指南.md`**
（技术栈、模块职责、数据流、架构图）。
